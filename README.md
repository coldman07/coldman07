## `01` — The Operator

I'm a cybersecurity enthusiast and developer interested in understanding how systems fail, how adversaries exploit weaknesses, and how better tools can improve security.

My approach combines hands-on security research with practical engineering. I enjoy investigating vulnerabilities, analyzing suspicious behavior, experimenting with cryptographic systems, and building tools that solve real technical problems.

**My focus isn't just finding weaknesses. It's understanding the mechanics behind them.**

- **Offensive security:** Reconnaissance, enumeration, web application testing, and adversary techniques.
- **Digital forensics:** Evidence-oriented investigation, artifact analysis, and understanding system activity.
- **Defensive security:** Ransomware behavior detection, heuristic monitoring, and incident response automation.
- **Security development:** Python utilities, cryptographic applications, and security-focused tooling.
- **AI engineering:** Exploring local language models and cybersecurity knowledge systems.
